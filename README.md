# Volley Hub

Адаптивный интерфейс волейбольных игр: кабинет организатора, форма создания игры, расписание и результаты матчей.

Сайт: https://prod-xeinty.github.io/volley-hub/

Чистые HTML, CSS и JavaScript. Откройте index.html в браузере. Данные демонстрационные, изменения сохраняются в localStorage. Backend и оплата не подключены.
